# Web Development I – Lab Assignment 3

## Responsive Personal Portfolio Website (CSS Advanced)

### Description
This project is a personal portfolio website developed using HTML5 and CSS3. It showcases my introduction, skills, projects and contact information through a clean and responsive design.

### Features
- Responsive navigation bar
- Hero section with profile image
- About section
- Skills section using CSS Grid
- Projects section using CSS Grid
- Contact form
- Hover effects and transitions
- CSS animations
- Responsive layouts for desktop, tablet and mobile devices

### Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

### How to View the Website
1. Download the repository.
2. Extract the downloaded ZIP file.
3. Open the project folder.
4. Open `portfolio2.html` in Google Chrome.

### Responsive Behaviour Testing
1. Open the website in Google Chrome.
2. Press F12 to open Developer Tools.
3. Click Toggle Device Toolbar.
4. Change the viewport width to test different screen sizes.

### CSS Breakpoints
- 900px – Tablet layouts
- 600px – Mobile layouts
- 400px – Small mobile layouts

### Screen Sizes to Test
- 1920px – Desktop
- 1366px – Laptop
- 768px – Tablet
- 390px – Mobile
